# 📌 Project Description

**Employee Management System** is a menu-driven Python application developed using Object-Oriented Programming (OOP) concepts. The system allows users to create and manage different types of objects such as **Person**, **Employee**, **Manager**, and **Developer**. It demonstrates important OOP principles including **Inheritance, Multilevel Inheritance, Method Overriding, Encapsulation (Getter & Setter), Constructors, Destructors, and Polymorphism** through an interactive Command Line Interface (CLI). :contentReference[oaicite:0]{index=0}

---

# ✨ Features

- 👤 Create Person
- 👨‍💼 Create Employee
- 🧑‍💼 Create Manager
- 👨‍💻 Create Developer
- 📄 Display Object Details
- 🔒 Encapsulation using Getter & Setter Methods
- 🔄 Method Overriding
- 🧬 Inheritance (Single & Multilevel)
- ✅ Subclass Verification using `issubclass()`
- 🚪 Exit Program

# 📥 Installation

### Step 1
Install **Python 3.x** from:

https://www.python.org/downloads/

### Step 2
Download the project file:

```
OOP-wrapper.py
```

### Step 3
Open **Command Prompt** or **Terminal**.

### Step 4
Navigate to the project folder.

### Step 5
Run the program:

```bash
python "OOP-wrapper.py"
```

# ▶️ Usage

Run the program and choose an option from the main menu.

```
1. Create Person
2. Create Employee
3. Create Manager
4. Create Developer
5. Show Details
6. Exit
```

Enter the required information and follow the on-screen instructions.
